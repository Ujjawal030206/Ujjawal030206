### Projects

**[Agent Reliability Engine](https://github.com/Ujjawal030206/agent-reliability-engine)** · [live demo](https://agent-reliability-engine.onrender.com/)

Continuous integration for autonomous agents. Generates realistic and adversarial
test scenarios, runs the agent in a sandbox, classifies *why* it failed using
deterministic safety rules alongside an LLM judge, and tracks a reliability
scorecard across versions. — *Python, FastAPI, SQLite*

**[CivicAI](https://github.com/Ujjawal030206/civicai)** · [live demo](https://ujjawal030206.github.io/civicai/)

Turns legal and bureaucratic language into a guided path: rights navigation, RTI
application drafting, and welfare scheme eligibility. Every mode is grounded in an
embedded knowledge base, so answers cite the Act or scheme they come from rather
than inventing one. — *React, Vite, Tailwind CSS, Gemini API*

**[FlyRank ML Internship](https://github.com/Ujjawal030206/Flyrank-ML-Internship)**

Content-refresh opportunity scoring for SEO — feature preparation, model
comparison, and a ranked review queue built over an anonymized dataset.
— *scikit-learn, pandas, DuckDB*
